## Featured Project

### [Event Ticketing API](https://github.com/taras-maleryk/event-ticketing)

Backend system for event discovery, concurrent seat reservation, and Stripe-powered ticket checkout.

- Designed concurrency-safe seat reservations using PostgreSQL constraints and row-level locking
- Implemented Stripe Checkout with idempotent payment attempts and deduplicated webhook processing
- Built JWT authentication with refresh-token rotation, replay protection, and role-based authorization
- Added Docker-based infrastructure, GitHub Actions CI, and 100+ unit, integration, and concurrency tests

**Stack:** Python · FastAPI · PostgreSQL · SQLAlchemy · Pydantic · Redis · Celery · Alembic · Stripe · Docker
